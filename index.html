01 — About

Axiom is a lot of things.

One name, many directions. Axiom is a home for things built carefully, kept small, and made to last.

It started the way most things do, with an idea that wouldn't stay put. It kept growing sideways, and the name stuck. We build what we want to exist and share it when it's ready.

02 — Principles

How we think about it.

01

Keep it plain.

If something can be said or built simply, it should be. Cleverness is a cost, not a feature.

02

Fewer parts.

Every moving piece is something that can break. We cut until it's only what's needed.

03

Own the details.

The small stuff is the whole experience. We sweat it so you don't have to notice it.

04

Make it ours.

Independent, opinionated and a little odd on purpose. No committee, no filler.

03 — The mark

A truth that needs no proof.

ax·i·om  / nounA statement accepted as true without needing to be proven. The starting point everything else is built on.

The orbit wraps the name the way everything we make circles back to a few fixed ideas. The four-point star sits in the middle of the O, the one fixed point everything else moves around.
