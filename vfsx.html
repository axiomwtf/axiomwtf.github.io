Backups you can actually trust.

vfsx packs a directory into a .vfsx.tar.* file that carries its own Ed25519 signature, manifest and index. Checking it takes one command.

.vfsx is part of the name, as in dir.vfsx.tar.zst, so you can always tell it apart from an ordinary tarball.

Exactly one file, nothing on the side.

I

Signed

A single Ed25519 signature covers every byte.

II

Indexed

A content-addressed manifest and index allow random access and hash checks.

III

Deduplicated

Identical files are stored once, inside the archive.

IV

Incremental

A delta only holds what its base doesn't.

vfsx create ./project -o project.vfsx.tar.zst   # makes your key on first run
vfsx key export -o mykey.vfsx                   # give this to others
vfsx verify project.vfsx.tar.zst -k mykey.vfsx  # they check your archive

zstd by default; use -c xz or -c gzip instead.

One base, one delta.

Files that haven't changed are referenced by hash, never copied again.

StepCommandWhat happens
Create a deltavfsx create --base base.vfsx.tar.zstThe new archive points to the base by hash and stores only new or changed files.
Extractvfsx extract delta.vfsx.tar.zst --base base.vfsx.tar.zstThe signed manifest records the base's hash, so the wrong base is rejected.

Your key is made the first time you sign.

The first vfsx create generates an Ed25519 identity in ~/.config/vfsx/keys/. Export the public half as a .vfsx file to share.

Generate
vfsx key gen [--force] creates identity.pub and identity.priv
Export
vfsx key export -o mykey.vfsx --owner "alice@laptop" writes the public key plus details
Import
vfsx key import mykey.vfsx trusts a key so -k isn't needed later
Verify
vfsx verify archive.vfsx.tar.zst -k mykey.vfsx checks the signature and every hash

Eight commands.

vfsx create  [DIR] [-o OUTPUT] [-c ZSTD|XZ|GZIP] [--level N] [--base ARCHIVE] [--follow-links]
vfsx extract ARCHIVE [-C DIR] [--force] [--base ARCHIVE] [-k KEY]
vfsx list    ARCHIVE [--json] [--detail]
vfsx verify  ARCHIVE [-k KEY]
vfsx key gen [--force]
vfsx key export [-o FILE] [--owner NAME]
vfsx key import KEY
vfsx key show

Defaults: current folder, zstd level 3.
